# Task 1 — Генератор паролей

Проект содержит консольный генератор случайных паролей и простой веб-интерфейс на Flask. Пароль состоит из латинских букв верхнего и нижнего регистра и цифр. Для выбора символов используется модуль `secrets`.

## Требования

- Python 3.9 или новее.
- Flask нужен только для запуска веб-версии.

## Консольная версия

Из каталога `task_1` запустите:

```bash
python password_generator.py
```

Программа запросит длину пароля и выведет сгенерированный пароль. Длина должна быть положительным целым числом.

## Веб-версия

Установите Flask:

```bash
python -m pip install Flask
```

Запустите приложение:

```bash
python app.py
```

Откройте в браузере адрес, показанный Flask при запуске (по умолчанию `http://127.0.0.1:5000`). Введите длину пароля и нажмите кнопку генерации.

> Это учебное локальное приложение. Веб-сервер Flask запускается в режиме отладки; не используйте встроенный сервер для публикации приложения в интернете.
